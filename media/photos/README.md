# media/photos/

Photos of the build, the case and RadZilla in use.

## Guidelines

- Format: **JPEG** (`.jpg`)
- Size: max. **2000 px** on the long side, quality ~85 % – keeps the
  repository small (GitHub limit: 100 MB per file)
- Naming: lowercase, no spaces, e.g. `build-01-board.jpg`,
  `case-front.jpg`, `in-use-uranium-glass.jpg`
- **Privacy:** remove location data (GPS / EXIF) before committing.
  macOS: open in *Preview* → *Tools → Show Inspector* → *GPS* →
  *Remove Location Info*, or export via *Photos* with "Include location"
  switched off.
